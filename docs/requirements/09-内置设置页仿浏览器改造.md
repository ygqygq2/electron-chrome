# 09-内置设置页仿浏览器改造

## 背景

当前 `chrome://settings` 已经支持主题同步，但页面结构仍偏展示卡片，不像用户参考图里的传统浏览器设置页：缺少左侧分类导航、顶部搜索、分组表单区与更克制的留白。

用户明确表示“设置页面也可以抄，以后慢慢加功能”，因此这一轮需要先把设置页外观和信息架构做得更像浏览器，再为后续功能填充留出位置。

## 用户故事

- 作为用户，我希望设置页看起来像浏览器原生设置，而不是单独的演示页。
- 作为用户，我希望一眼看到左侧分类导航，知道后续还能继续扩展功能。
- 作为用户，我希望浅色 / 深色模式下，设置页都与顶部壳层保持统一。

## 功能范围

### 本次范围

- 将 `chrome://settings` 改造成浏览器式两栏布局
- 新增左侧分类导航视觉结构
- 新增顶部搜索框与右上操作按钮占位
- 新增“启动页面 / 搜索 / 默认浏览器 / 关闭时”等基础设置分组
- 保持主题跟随 `light / dark / system`

### 非目标

- 不实现真实设置持久化
- 不实现完整搜索过滤逻辑
- 不接入真实默认浏览器检测
- 不实现所有分类页跳转

## 数据流 / 状态说明

- 设置页仍由主进程生成内部 HTML
- 主题由主进程传入，页面根据 `theme.resolved` 渲染浅深样式
- 当前分类导航先作为静态结构，为后续真实分类切换预留

## 验收标准

- `chrome://settings` 打开后为明显的左侧导航 + 右侧内容布局
- 页面视觉风格接近用户提供的浏览器设置参考图
- 浅色与深色主题下都能正常显示
- 页面包含搜索框、分组标题、表单项/复选项占位
- 不影响现有主题同步、标签页打开与构建流程

## 与 video-downloader 的协作关系

- 这一版设置页结构可作为主项目未来“浏览器模式设置中心”的视觉与布局参考。
- 后续若接入真实偏好项，可沿用当前分组与占位结构逐步替换为真实配置。
