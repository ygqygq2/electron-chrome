# 09-内置设置页仿浏览器改造设计

## 目标

让 `chrome://settings` 更像传统桌面浏览器设置页面：左侧窄导航，右侧为分组表单内容，整体更克制、更轻、更容易持续扩展。

## 布局设计

### 整体布局

- 页面采用两栏布局：
  - 左侧：固定宽度导航栏
  - 右侧：设置内容区
- 内容区顶部包含搜索框与“恢复默认设置”按钮占位
- 主内容采用纵向分组，而不是卡片瀑布流

### 左侧导航

导航项优先贴近用户截图的浏览器设置语义，首版包括：

- 基本设置
- 界面设置
- 标签设置
- 下载设置
- 鼠标手势
- 快捷键
- 实验室

其中“基本设置”为默认高亮项。

### 右侧内容分组

首版展示以下分组：

1. 启动页面
2. 搜索
3. 默认浏览器
4. 关闭时

每个分组包含轻量表单、单选/复选项与说明文字占位。

## 视觉设计

- 浅色主题优先贴近截图：更亮的背景、更轻的分隔线、更细的文字层级
- 深色主题保留同一布局，但切换为暗色 token
- 左侧导航选中态用蓝色背景或蓝色描边强调
- 表单控件以“浏览器设置页占位组件”方式实现，不追求真实表单提交

## 交互策略

- 搜索框本轮只作视觉占位，不实现过滤
- 左侧导航本轮只做静态高亮，不实现分类跳转
- 右上角按钮只作样式占位，便于后续接功能

## 扩展策略

- 后续如需真实设置项，可把当前 HTML 片段拆分为模板函数
- 后续如需分类切换，可把左侧导航变成锚点或局部状态驱动
- 后续如需真实配置持久化，可逐项映射到主进程偏好设置

## 验证重点

1. 页面是否明显更像浏览器设置中心
2. 与顶部壳层的主题是否一致
3. 布局在较宽窗口下是否稳定、清晰
4. 是否为后续真实功能预留了足够空间
