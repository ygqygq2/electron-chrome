# 04-浅色浏览器壳视觉重构设计

## 设计目标

本轮不重做功能，而是重做观感：在保留现有标签、自适应、地址输入、菜单弹出等能力的前提下，让 `electron-chrome` 更接近用户参考图中的浅色浏览器壳。

目标分为四点：

1. 从“深色工具面板”转向“浅色浏览器窗体”。
2. 压缩顶部厚度，让结构更紧凑。
3. 让地址栏成为视觉中心。
4. 让标签、按钮、菜单、状态区属于同一套轻量 UI 语言。

## 视觉语言

### 总体基调

- 使用浅灰、白色、低饱和蓝作为主色。
- 避免大面积深色渐变与过重阴影。
- 用细边框、浅阴影、轻分层替代厚重面板感。

### 层级划分

1. **壳层背景**：浅灰浏览器顶栏
2. **活动标签**：白色卡片，和页面视觉连在一起
3. **非活动标签**：浅灰卡片，弱于活动标签
4. **地址栏**：白色主输入区，作为最强视觉焦点
5. **次级按钮**：浅灰圆角按钮
6. **主按钮**：蓝色强调按钮，但面积收敛，不喧宾夺主

## 结构设计

### 标签栏

- 标签栏与工具栏的背景统一为浅灰顶部区域。
- 活动标签做成白底、轻边框、顶部略圆、底部贴合页面。
- 非活动标签使用更浅的灰色，并降低文字对比度。
- `+` 按钮缩小，作为标签轨道的自然延伸，而不是独立的大按钮。

### 工具栏

- 后退 / 前进 / 刷新按钮改为轻量化圆角浅灰按钮。
- 地址栏放大白色输入容器，承担主要视觉重量。
- “打开”按钮保留，但尺寸收敛，避免像运营按钮。
- 菜单按钮改成更轻的图标按钮或短文案按钮，融入右侧工具组。

### 状态区

- 状态文本只保留轻量辅助信息。
- 文本字号缩小，颜色减弱，避免抢占工具栏注意力。

## 间距与尺寸

### 高度策略

- 顶部整体高度从当前偏厚方案进一步压缩。
- 标签栏与工具栏之间的间距缩小。
- 控件高度统一，减少上下跳动感。

### 圆角策略

- 统一使用克制圆角：
  - 标签：小圆角
  - 地址栏：中等圆角 / 胶囊
  - 按钮：中小圆角
- 避免不同控件圆角体系割裂。

## 兼容原则

- 尽量只改 HTML 结构和 CSS，不碰主进程与 bridge 协议。
- 状态文本保留，避免影响现有调试感知。
- 自适应标签算法保持不动，只调整表现层。

## 验证重点

1. 是否明显比当前版本更接近参考图的“浏览器感”
2. 顶部是否更轻、更整洁
3. 地址栏是否成为核心焦点
4. 菜单按钮与状态区是否不再突兀
5. 标签区是否更像真实浏览器标签，而不是深色控制台标签
