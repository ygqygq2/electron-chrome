# 12-内置新标签页与主页对齐设计

## 目标

为 `electron-chrome` 提供一个真正的内置新标签页 / 浏览器主页，使其在观感和信息组织上更接近现代浏览器首页，同时保留项目自己的视觉语言。

## 设计原则

1. **借鉴结构，不复刻素材**：参考 360 / downloader 的布局层级，但不直接使用相同背景图、图标编排和文案。
2. **轻量优先**：首页应打开快、结构清晰，不做内容流堆叠。
3. **浏览器入口感**：用户一眼能看出这是“浏览器首页”，而不是普通网页。
4. **主进程模板生成**：仍沿用内部页由主进程输出 HTML 的模式。

## 信息架构

页面分为 5 个区域：

1. 顶部右上功能胶囊
2. 中央品牌标题 / 副标题
3. 中央搜索区
4. 快捷入口 chips 与网站网格
5. 底部状态提示

## 视觉策略

- 使用自绘渐变 / 光晕 / 模糊叠层代替外部版权背景图
- 搜索框使用圆角胶囊，但更简洁、克制
- 快捷入口使用半透明卡片风格，兼顾轻量与层次
- 深色模式下保持同样布局，颜色 token 自动切换

## 交互策略

- 搜索框回车提交到搜索引擎
- 快捷入口点击打开对应网站
- 可在页面内直接跳到历史、下载、设置等内部页

## 路由与入口

- `xuewuya://home` 作为内置主页 URL
- `新建标签页`、`主页按钮`、启动后的首个页面都打开该 URL

## 验证重点

1. 新标签页是否已经不再直接打开普通外部网页
2. 视觉是否更像浏览器首页而非示例页
3. 搜索与快捷入口是否可用
4. 浅色 / 深色主题是否一致
5. 是否避免了第三方产品的直接复制
