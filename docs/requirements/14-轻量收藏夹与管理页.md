# 轻量收藏夹与管理页

## 用户故事

- 作为用户，我希望点击顶部收藏夹按钮时，看到真实的收藏列表，而不是“开发中”占位。
- 作为用户，我希望把当前网页一键加入收藏夹，后续可以快速再次打开。
- 作为用户，我希望有一个内置收藏管理页，能查看、编辑、删除收藏，并按文件夹做基础整理。

## 功能范围

- 新增 `chrome://favorites` 内置收藏管理页
- 收藏夹按钮左键弹出真实收藏菜单
- 支持“收藏当前页面”
- 地址栏后的收藏星标作为快捷入口：未收藏时单击立即收藏，已收藏时显示黄色星星
- 支持基础文件夹管理：默认文件夹、创建子文件夹、按文件夹查看
- 支持收藏的新增、编辑、删除
- 支持在当前标签或新标签打开收藏网址
- 收藏数据持久化到本地用户数据目录

## 非目标

- 不实现云同步
- 不实现账号体系下的多端收藏同步
- 不实现复杂拖拽排序与树形重排
- 不实现导入/导出浏览器收藏文件

## 页面与模块

- 顶部收藏夹按钮弹出菜单
- `chrome://favorites` 收藏管理页
- 收藏数据持久化模块
- 收藏动作路由解析模块

## 数据与状态

- 收藏项字段：`id`、`title`、`url`、`folder`、`createdAt`、`updatedAt`
- 收藏文件夹字段：字符串路径，使用 `/` 表示层级
- 默认文件夹至少包含：`收藏栏`、`文档资料`、`项目相关`
- 收藏状态以本地持久化文件为准

## 交互规则

- 当前标签为内置页时，不允许“收藏当前页面”，星标置灰不可点
- 已存在相同 URL 的收藏时，再次收藏应更新标题/文件夹，而不是重复插入
- 收藏变更后，已打开的收藏管理页应自动刷新
- 收藏菜单默认展示最近更新的若干项，并提供“打开收藏管理页”入口

## 验收标准

- 点击收藏夹按钮，可以看到真实收藏菜单
- 可以把当前外部网页加入收藏夹
- 可以打开 `chrome://favorites` 并看到收藏列表
- 可以新增、编辑、删除收藏
- 可以新建文件夹，并把收藏保存到目标文件夹
- 关闭应用重启后，收藏仍然存在
- 收藏相关改动不影响正常网页浏览、输入、跳转与历史记录功能
