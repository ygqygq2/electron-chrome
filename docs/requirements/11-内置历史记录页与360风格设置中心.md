# 11-内置历史记录页与360风格设置中心

## 背景

当前 `electron-chrome` 已有简化版 `chrome://settings`、`chrome://downloads` 与 `chrome://extensions` 内置页，但仍缺少两个关键浏览器基础能力：

1. 没有可查看真实访问记录的 `chrome://history`
2. `chrome://settings` 还没有像 360 极速 X 那样拆成多分类设置中心

用户明确要求：

- `electron-chrome` 不只是 UI，要继续补一部分浏览器内部页功能
- 历史记录页需要对齐浏览器常见形态
- 设置页要尽量参考 360 极速 X 的设置页截图，能抄的抄，当前壳层做不到的不要硬上
- 本轮优先做“能真实生效”的部分，不能实现的只保留静态占位

## 用户故事

- 作为用户，我希望输入 `chrome://history` 时，能看到真实访问过的页面记录，而不是空白占位页。
- 作为用户，我希望 `chrome://settings` 更像传统浏览器设置中心，有左侧分类导航和分组内容区。
- 作为用户，我希望设置页至少能在视觉结构上接近 360 设置页，并且其中一部分配置能够真实反映当前壳状态。
- 作为开发者，我希望内部页仍由主进程统一生成，便于主题同步和后续扩展。

## 功能范围

### 本次范围

- 新增 `chrome://history` 内置页
- 主进程记录外部网页访问历史，并做本地持久化
- 历史页展示最近访问记录、访问时间、标题与 URL
- 新增 / 扩展 `chrome://settings/*` 分类页，覆盖：
  - `chrome://settings/browser`
  - `chrome://settings/uiStyle`
  - `chrome://settings/tabOptions`
  - `chrome://settings/downloadSetting`
  - `chrome://settings/tpMoreMouseGesture`
  - `chrome://settings/shortcut`
  - `chrome://settings/advanced`
  - `chrome://settings/lab`
  - `chrome://settings/privacySecurity`
- 设置页左侧导航可切换分类
- 设置页内容优先展示当前壳层已存在或可读到的真实状态，例如：
  - 主题来源与当前主题
  - 工具栏按钮显隐偏好
  - 恢复关闭标签能力说明
  - GPU 运行模式
  - 已记录历史条数
- 菜单中新增历史记录入口
- 支持地址栏直接输入 `chrome://history` 与 `chrome://settings/...`

### 非目标

- 不实现完整浏览器书签管理系统
- 不实现所有设置项的真正可编辑与持久化
- 不实现复杂历史搜索、删除单条历史、同步云历史
- 不实现和系统默认浏览器设置的深度联动
- 不实现截图中所有 360 专有能力

## 数据流 / 状态说明

### 历史记录

- 主进程维护历史记录数组并写入 `userData` 下单独 JSON 文件
- 外部网页导航成功后记录访问项
- 内置页、`data:` 页面、失败页不进入历史
- `chrome://history` 页面渲染时直接读取主进程当前快照

### 设置页

- 设置页继续由主进程生成 HTML
- 地址栏输入 `chrome://settings/<section>` 时，主进程根据 section 生成对应内容
- 左侧导航点击时，在内置页内部跳转到对应 section URL
- 已有运行时偏好和窗口状态可作为只读/半静态内容投影到设置页

## 验收标准

- 输入 `chrome://history` 可打开历史记录页
- 历史记录页至少展示最近访问条目、标题、URL、时间
- 访问新网页后，历史页刷新可看到新增记录
- 输入 `chrome://settings/browser` 等设置子路径时，可打开对应分类页
- 设置页左侧分类结构与 360 风格接近
- 当前已有壳层信息（主题、工具栏偏好、GPU 状态等）可在设置页中看到
- 无法真实实现的项目只做静态占位，不出现报错或假交互
- `pnpm lint`、`pnpm type-check`、`pnpm stylelint` 通过

## 与 video-downloader 的协作关系

- 这套历史记录与分类设置中心能力可作为未来主项目浏览器工作台的基础设施预研。
- 历史模型、内置页信息架构与设置分类命名，后续可以向主项目迁移或映射。
