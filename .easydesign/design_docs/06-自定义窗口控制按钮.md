# 06-自定义窗口控制按钮设计

## 目标

在保留 `titleBarStyle: hidden` 的前提下，为浏览器壳补齐最基础的桌面窗口控制：

- 最小化
- 最大化 / 还原
- 关闭

重点不是做得多花，而是让它：**能被用户一眼找到、行为符合桌面习惯、视觉和当前壳层统一。**

## 结构设计

### 按钮位置

- 将窗口控制区放在顶部工具栏最右侧
- 菜单按钮与状态信息保留在右侧，但窗口按钮要位于最外层，形成标准桌面软件收尾区

### 按钮组成

从左到右：

1. 最小化
2. 最大化 / 还原
3. 关闭

其中关闭按钮为最强风险操作，需要 hover 态更明确。

## 状态设计

渲染层需要感知：

- 当前窗口是否已最大化

因此在 shell state 增加：

- `windowState.isMaximized`

按钮第二项根据该状态切换：

- 未最大化：显示“最大化”
- 已最大化：显示“还原”

## 主进程设计

### IPC 能力

新增窗口控制命令：

- 最小化窗口
- 切换最大化 / 还原
- 关闭窗口

### 状态同步

在窗口：

- maximize
- unmaximize
- enter-full-screen（可选）
- leave-full-screen（可选）

等状态变化时，重新广播 shell state。

## 渲染层设计

### 交互

- 每个按钮单独可点击
- hover 态明确
- close hover 使用偏红风险态
- 所有按钮都必须 `-webkit-app-region: no-drag`

### 视觉

- 使用与当前工具栏按钮一致的边框、圆角和高度体系
- 关闭按钮可在 hover 时切到暖色 / 红色背景
- 深色主题下使用对应暗色 token，不要出现刺眼白块

## 兼容原则

- 不依赖平台原生标题栏按钮
- 继续使用隐藏标题栏方案
- 保持顶部拖拽区域不被按钮破坏

## 验证重点

1. 用户是否能一眼发现关闭按钮
2. 最大化/还原按钮状态是否正确
3. 右侧按钮组是否和现有菜单按钮协调
4. 深色/浅色模式下是否都可读
