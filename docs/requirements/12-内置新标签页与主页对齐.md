# 12-内置新标签页与主页对齐

## 背景

当前 `electron-chrome` 的“新标签页”实际上仍直接打开外部网页，缺少真正的浏览器内置首页承载，因此与用户期望中的下载器首页 / 360 风格新标签页差距很大。

用户希望：

- 新标签页明显更好看
- 视觉上参考 `video-downloader` 与 360 极速 X 的首页组织方式
- 但要避免一模一样照抄，保留自己的视觉语言

## 用户故事

- 作为用户，我打开新标签页时，希望看到一个真正的浏览器首页，而不是直接跳到普通网页。
- 作为用户，我希望首页有清晰的搜索入口、常用站点快捷入口和轻量功能区。
- 作为用户，我希望这个新标签页和整个浏览器壳保持同一套主题风格。

## 功能范围

### 本次范围

- 新增内置主页 `xuewuya://home`
- 新标签页默认打开该内置主页
- 主页按钮打开该内置主页
- 页面包含：
  - 顶部轻量工具条提示
  - 中央搜索框
  - 快捷站点网格
  - 常用入口 chips / 快捷入口
  - 底部轻量说明或状态信息
- 浅色 / 深色主题同步
- 搜索框可提交到真实搜索引擎

### 非目标

- 不接入复杂个性化推荐流
- 不实现账号体系 / 云同步
- 不直接复刻 360 的背景图、模块细节或专属文案
- 不实现完整壁纸管理系统

## 数据流 / 状态说明

- 新标签页仍由主进程生成内部 HTML
- 地址 `xuewuya://home` 由主进程识别为内部页
- 新建标签、主页按钮、默认首页入口统一指向该内部页
- 搜索表单直接提交到外部搜索引擎页面

## 验收标准

- 新建标签页打开 `xuewuya://home`
- 主页按钮打开 `xuewuya://home`
- 页面视觉明显优于当前直接打开外部网页的方案
- 页面包含搜索框、快捷入口、背景层次与主题同步
- 视觉可借鉴同类产品，但不会构成逐像素复刻
- `pnpm lint`、`pnpm type-check`、`pnpm stylelint` 通过

## 与 video-downloader 的协作关系

- 可作为主项目浏览器工作台首页的轻量原型参考
- 搜索框、快捷入口、主题映射方式后续可向主项目迁移
