# 10-工具栏按钮布局与显隐持久化

## 背景

当前 `electron-chrome` 的顶部工具栏按钮顺序和显隐是写死的，用户无法像浏览器那样通过右键快速调整按钮位置，也无法控制某些按钮是否显示。

用户明确要求：

- 恢复关闭标签按钮，右键时可以选择放在左边还是右边
- 收藏夹按钮，也需要同样的左右放置能力
- 一些按钮可以选择显示 / 隐藏
- 这些设计需要支持持久化

## 用户故事

- 作为用户，我希望右键“恢复关闭标签”按钮时，能把它放到工具栏左边或右边。
- 作为用户，我希望右键“收藏夹”按钮时，也能把它放到左边或右边。
- 作为用户，我希望能控制常用按钮是否显示，让顶部壳层更符合我的习惯。
- 作为用户，我希望我调整过的布局在重启应用后仍然保留。

## 功能范围

### 本次范围

- 新增收藏夹按钮
- 为“恢复关闭标签”“收藏夹”提供右键布局菜单
- 支持按钮位置：左侧 / 右侧
- 支持部分工具栏按钮显示 / 隐藏
- 工具栏布局偏好持久化到本地配置
- 主进程向渲染层下发工具栏配置状态

### 非目标

- 不实现完整收藏夹管理系统
- 不实现拖拽排序
- 不实现任意按钮的自由像素级拖动
- 不实现多套布局方案切换

## 数据流 / 状态说明

- 主进程维护工具栏偏好设置，写入运行时偏好文件
- 渲染层根据配置决定按钮是否显示，以及渲染在左侧还是右侧分组
- 右键按钮后由主进程弹出原生菜单
- 菜单操作修改主进程配置并立即广播到渲染层
- 应用重启后继续读取上次保存的按钮布局配置

## 首版可配置按钮

- 主页按钮：显示 / 隐藏
- 恢复关闭标签按钮：显示 / 隐藏、左侧 / 右侧
- 收藏夹按钮：显示 / 隐藏、左侧 / 右侧
- 下载按钮：显示 / 隐藏
- 扩展按钮：显示 / 隐藏

## 验收标准

- 顶部新增收藏夹按钮
- 右键恢复关闭标签按钮时，可切换左侧 / 右侧位置
- 右键收藏夹按钮时，可切换左侧 / 右侧位置
- 菜单中可切换部分按钮显示 / 隐藏
- 调整后工具栏立即更新
- 重启应用后按钮位置和显隐保持一致
- `pnpm type-check`、`pnpm lint`、`pnpm stylelint`、`pnpm build` 通过

## 与 video-downloader 的协作关系

- 这套工具栏偏好配置机制可直接复用于主项目浏览器模式，后续更多快捷按钮都可沿用同一持久化结构扩展。
- 收藏夹、历史、下载等浏览器高频入口未来可统一纳入该偏好系统。
